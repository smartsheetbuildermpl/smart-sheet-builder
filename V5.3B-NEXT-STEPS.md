# Smart Sheet Builder V5.3B Next Steps

## What V5.3B Does Now

- Keeps the working V5.2.4 PNG/TIFF export engine.
- Keeps guest trial behavior: 2 free exports.
- Keeps registered free behavior: 5 total exports.
- Counts only final PNG/TIFF downloads as usage.
- Adds Supabase-ready API routes for auth, profile, guest usage, and export usage.
- Falls back to local test mode when Supabase env vars are missing.
- Adds Supabase tables for future subscriptions, credits, and subscriber-only design library.

## Before Production Testing

1. Create Supabase project.
2. Run `supabase-smart-sheet-v53b.sql`.
3. Add Vercel env vars from `SUPABASE-V5.3B-SETUP.md`.
4. Redeploy Vercel.
5. Confirm the app header says `Server protected`.

## Recommended V5.3C Upgrade

Move subscription decisions into a payment provider:

- Add checkout button when trial is finished.
- Add webhook route for successful payment.
- Set `profiles.plan = 'subscriber'`.
- Add admin page for updating role, plan, and status.
- Build the subscriber-only free design library UI.

## Important Security Note

The builder UI still runs in the browser, so customers can inspect front-end code. The real protection is keeping account state, usage count, plans, and downloads enforced by server/API/database rules.
