# Smart Sheet Builder V5.3A Next Steps

## What V5.3A Does Now

- Keeps the working V5.2.4 PNG/TIFF export engine.
- Adds an access bar above the builder.
- Gives guests 2 free exports.
- Gives registered free accounts 5 total exports.
- Counts only final PNG/TIFF downloads as usage.
- Shows a paywall/account modal when usage is finished.

## What Is Still Local In V5.3A

The account and usage counter are stored in browser local storage. This is good for testing the product flow, but it is not yet strong security because users can clear browser data.

## Recommended V5.3B Upgrade

Move these to Supabase:

1. Real email/password login using Supabase Auth.
2. Server-side usage checking before export.
3. `profiles` table with role and plan.
4. `usage_exports` table for PNG/TIFF export history.
5. Admin bypass and account blocking.
6. Subscriber-only design library foundation.

## Future Design Library

Add a `design_library` table with:

- `id`
- `title`
- `category`
- `preview_url`
- `file_url`
- `is_active`
- `subscriber_only`
- `created_at`

Subscribed users can browse and insert these designs into their gang sheet.
